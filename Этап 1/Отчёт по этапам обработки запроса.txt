Отчёт по этапам обработки запроса:
1.Клиент отправляет HTTPзапрос на порт 8080.
2.http.ListenAndServe принимает соединение, парсит запрос, создаёт *http.Request.
3.http.ServeMux сопоставляет путь запроса с зарегистрированным обработчиком.
4.Вызывается соответствующая функцияобработчик с http.ResponseWriter и *http.Request.
5.В обработчике проверяется метод (для /ping), устанавливается статускод, записывается тело ответа через ResponseWriter.
6.Сервер отправляет HTTPответ (статус, заголовки, тело) клиенту, закрывает соединение.
Проверка работы через браузер
1.Открыть в браузере:
ohttp://localhost:8080/ → отображается приветствие;
ohttp://localhost:8080/about → отображается описание проекта;
ohttp://localhost:8080/ping → отображается «pong».
Проверка через curl и анализ заголовков
1.Получить тело ответа:
ocurl http://localhost:8080/
ocurl http://localhost:8080/about
ocurl http://localhost:8080/ping
